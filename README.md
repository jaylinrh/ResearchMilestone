# Budget Tracker

A small desktop budget tracker made with Python, PySide6, and SQLite.

## Run it

```bash
python -m pip install -r requirements.txt
python app.py
```

The app automatically saves its database locally in `~/.budget_tracker/budget.db`.

## Included

- Income and expense entries with dates, categories, and notes
- Monthly income, expenses, and net balance
- Configurable monthly spending budget
- Clear under-budget / over-budget status
- Edit or delete existing transactions
